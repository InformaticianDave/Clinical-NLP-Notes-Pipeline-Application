1. Methods

Two independent large-language-model extraction runs over the same set of clinical notes were compared at the note level. Both runs used the same prompt and the same structured output schema; they differ only in the model that produced the output. The comparison evaluates (a) how often the two models reach the same clinical call, and (b) whether each model's output is internally consistent and evidence-grounded.

2. Statistical Analysis

2.1 Agreement

Raw agreement is the proportion of jointly scored rows on which the two models returned the same call. Raw agreement alone is misleading when a finding is uncommon: if a condition is present in 5% of notes, two models that both call almost everything negative will agree on roughly 95% of rows without either one being informative. Cohen's kappa is therefore reported alongside it.

2.2 Testing for a systematic difference

Because both models scored the same notes, the two sets of calls are paired, and an unpaired test would be invalid. McNemar's test is used instead. An exact binomial test is used at every sample size rather than the chi-square approximation.

4. Discussion

The two models returned the same call on 1,361 of 1,456 jointly scored notes (93.5%). Chance-corrected agreement was 0.782, conventionally read as substantial.

The discordant rows did not split evenly (exact McNemar p = 0.004): Gemini 2.5 Flash called 62 case(s) positive that LM Studio (Qwen3-32B) did not, against 33 in the opposite direction. Gemini 2.5 Flash therefore applies a systematically lower threshold for calling a case positive. Whether that reflects better sensitivity or more false positives cannot be settled from these two files, because neither is a reference standard; it requires chart review of the disagreement list.

4.1 Limitations

  • No reference standard was supplied, so nothing in this report establishes accuracy. Agreement between two models is not evidence that either is correct: models that share a blind spot agree perfectly.
  • Results reflect a single run of each model. Generation is not fully deterministic, so part of the observed disagreement is run-to-run variation rather than a stable difference between models.
  • The unit of analysis is the note, not the infant. A patient with several cranial studies contributes several rows, so these figures do not describe accuracy of a patient-level diagnosis.
  • Kappa is sensitive to how common the finding is. For a rare condition it can be low even when raw agreement is high, and it is not comparable across cohorts with different prevalence.
